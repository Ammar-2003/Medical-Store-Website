# Medicine Management System with AI-Powered Suggestions

A Django-based Medicine Management System designed for pharmacies and medical stores. The system helps manage medicines, inventory, sales, returns, reports, and provides AI-powered medicine suggestions based on user symptoms.

## Features

* Medicine inventory management
* Add, update, delete, and search medicines
* Stock quantity and expiry tracking
* Sales and billing management
* Return management
* Reports and dashboard overview
* AI-powered medicine suggestion system
* User-friendly web interface
* Django admin panel support

## Technology Used

* Python 3.12
* Django
* SQLite / Django Database
* HTML, CSS, JavaScript
* Bootstrap
* AI-based symptom and medicine suggestion logic

## Project Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Ammar-2003/Medical-Store-Website.git
cd Medical-Store-Website
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

### 3. Activate Virtual Environment

For Windows:

```bash
venv\Scripts\activate
```

For macOS/Linux:

```bash
source venv/bin/activate
```

### 4. Install Requirements

```bash
pip install -r requirements.txt
```

### 5. Apply Migrations

```bash
python manage.py migrate
```

### 6. Create Superuser

```bash
python manage.py createsuperuser
```

### 7. Run the Project

```bash
python manage.py runserver
```

Now open the project in your browser:

```bash
http://127.0.0.1:8000/
```

The AI-powered suggestion feature is designed only to provide basic medicine suggestions based on symptoms. It is not a replacement for professional medical advice, diagnosis, or treatment. Users should always consult a qualified doctor or pharmacist before using any medicine.
